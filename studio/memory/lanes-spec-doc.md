The LANES freight-MMO spec ("LANES — Game Design Spec v0.2") is a Claude Docs artifact: https://claude.ai/artifact/Q9jWMGsvTFpysZRGfHxf3z. Read it with the docs connector (`read` ref project → then the page node); the content comes back as XML too large for one tool result, so save it and extract text, including `codeBlock` CDATA (formulas, core tables, repo layout). Two embedded diagrams (FD money flow, roadmap) aren't readable as text.
